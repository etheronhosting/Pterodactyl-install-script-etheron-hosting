    Wings (node)

    Wings draait je gameservers in Docker. Na de installatie koppel je deze node aan je panel; dat kan ook hier in de browser.

    Gameservers kunnen dan een eigen MySQL-database krijgen. MariaDB wordt daarvoor op deze server geïnstalleerd.

    Je vult dit straks ook in het panel in (Admin → Databases).

      Bezig met installeren…

      Je kunt deze pagina sluiten en later opnieuw openen met dezelfde link; de installatie gaat gewoon door.

        Node koppelen aan je panel

        1. Log in op je panel en ga naar Admin → Nodes → Create New.
        2. Vul bij FQDN het domein of IP-adres van deze server in.
        3. Open daarna het tabblad Configuration van de node en kopieer de tekst.
        4. Plak die tekst hieronder en klik op Wings starten.
