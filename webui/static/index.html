    Wings (node)

    Wings draait je gameservers in Docker. Na de installatie koppel je deze node aan je panel; dat kan ook hier in de browser.

    Databases voor gameservers

    Gameservers kunnen dan een eigen MySQL-database krijgen, bijvoorbeeld voor plugins.

    Je vult dit straks ook in het panel in (Admin → Databases).

        Node koppelen aan je panel

        We maken in je panel een locatie en een node aan, voegen poorten voor gameservers toe en starten Wings. Je hoeft daarvoor niets in het panel te doen.

        Maak in je panel een sleutel aan via Admin → Application API → Create New. Zet Locations, Nodes en Allocations op Read & Write.

        Korte naam, bijvoorbeeld nl of ams1. Bestaat hij al, dan gebruiken we die.

        Eén poort of een reeks van maximaal 1000 poorten. Ze gaan ook open in de firewall.

        De databases voor gameservers worden meteen ook ingesteld en in je panel gezet.
